# AI mock GLB assets

Generated by:

```bash
node scripts/generate-mock-glb.mjs
```

These are **studio visualization meshes** (band + gallery + four-prong head + faceted stone; halo / pavé variants), not Hunyuan / AI manufacturing CAD.

| File | Description |
|------|-------------|
| `ring-diamond*.glb` | Four-prong solitaire (rose / yellow / white metal) |
| `ring-ruby.glb` / `ring-sapphire.glb` / `ring-emerald.glb` | Colored center stones |
| `ring-halo*.glb` | Halo setting |
| `ring-pave*.glb` | Pavé band accents |
| `necklace.glb` etc. | Simple metal loop placeholders |

Re-run the script after changing geometry, then commit the updated `.glb` files so Vercel serves them.
