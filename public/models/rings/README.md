# Ring GLB assets

Place production ring models here using the model slug as the filename:

- `solitaire-classic.glb`
- `halo-petite.glb`
- `east-west.glb`

Public URL path: `/models/rings/<slug>.glb`

When a GLB is missing, the JewelryViewer renders a procedural torus + gem with metal/stone materials from the configurator.
