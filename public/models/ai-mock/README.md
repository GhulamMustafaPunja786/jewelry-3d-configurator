# AI mock GLB assets (catalog visualization)

Generated by:

```bash
node scripts/generate-mock-glb.mjs
```

These are **studio visualization meshes**, not Hunyuan / manufacturing CAD.

## Ring anatomy (v3)

- Tapered band (thicker at head, thinner at bottom)
- 4-prong basket gripping a seated faceted center stone
- Optional pavé (embedded in shoulders) and halo

## Library

| Pattern | Description |
|---------|-------------|
| `ring-solitaire-{yellow\|white\|rose}.glb` | Classic 4-prong |
| `ring-pave-{yellow\|white\|rose}.glb` | Solitaire + pavé shoulders |
| `ring-halo-{yellow\|white\|rose}.glb` | Halo around center stone |
| `ring-ruby/sapphire/emerald.glb` | Colored center stones |
| Legacy `ring-diamond*.glb` | Aliases for older DesignVersion URLs |

Re-run the script and commit `.glb` files after geometry changes.
